# LEC 09 애니메이션 뷰어 개발 문서

## 1. 문서 목적

`PRE_PRD.md`의 사전 조건을 실제 개발에 사용할 수 있는 요구사항과 작업 순서로 구체화한다.

## 2. 개발 환경

| 항목 | 내용 |
| --- | --- |
| 언어 | Python |
| 그래픽 라이브러리 | pico2d |
| 실행 파일 | `sonic_animation_viewer.py` |
| 스프라이트 리소스 | `sonic-sprite.png` |
| 캔버스 크기 | 1200 x 600 |
| 구현 위치 | `Labs/LEC09` |

프로그램은 실행 파일과 스프라이트 이미지를 사용하는 단일 애니메이션 뷰어로 구현한다. 추가 이미지나 외부 네트워크 리소스는 사용하지 않는다.

## 3. 제품 목표

Sonic 스프라이트 이미지에 포함된 모든 동작을 원본 크기의 4배로 표시하고, 정해진 반복과 전환 규칙에 따라 자동 재생한다. 마지막 동작까지 재생한 뒤 첫 동작으로 돌아가 전체 애니메이션을 계속 순환한다.

## 4. 핵심 요구사항

### 4.1 리소스와 실행

- Python과 pico2d를 사용한다.
- 실행 파일은 `sonic_animation_viewer.py` 하나로 구성한다.
- `sonic-sprite.png`를 입력 리소스로 사용한다.
- 프로그램 실행 시 1200 x 600 크기의 캔버스를 연다.
- 스프라이트 시트의 실제 크기와 프레임 경계를 확인하여 한 프레임에 캐릭터 여러 개가 포함되지 않도록 좌표를 정의한다.

### 4.2 프레임 출력

- 이미지에 포함된 모든 동작을 재생 대상으로 등록한다.
- 각 프레임은 스프라이트 시트에서 `clip_draw`로 잘라 출력한다.
- 출력 크기는 각 프레임의 원본 크기에서 가로·세로 모두 4배로 확대한다.
- 프레임 좌표는 이미지 영역을 벗어나지 않아야 한다.
- 한 프레임에는 캐릭터 하나만 표시되어야 한다.

### 4.3 동작 전환

- 각 동작의 프레임을 등록된 순서대로 재생한다.
- 하나의 동작은 5회 반복한다.
- 5회 반복이 끝나면 마지막 프레임을 유지한 채 1초 정지한다.
- 1초 정지 후 다음 동작으로 전환한다.
- 마지막 동작이 끝나면 첫 동작부터 다시 재생한다.
- 동작별 프레임 수와 좌표는 실제 스프라이트 시트를 분석한 결과를 기준으로 기록한다.

### 4.4 화면 갱신과 종료

- 프레임마다 캔버스를 지우고 새 프레임을 그린 뒤 화면을 갱신한다.
- 창 닫기 이벤트를 받으면 정상적으로 종료한다.
- `ESC` 키를 누르면 정상적으로 종료한다.
- 종료 시 pico2d 캔버스를 닫는다.

## 5. 제외 범위

- 동작을 직접 선택하는 사용자 인터페이스
- 재생·일시정지·배속 조절 버튼
- 스프라이트 시트 편집 기능
- 이미지 형식 변환 기능
- 사운드와 배경 음악
- 사용자 설정 저장

## 6. 구현 원칙

- 최종 기능을 한 번에 구현하지 않고 작은 실행 가능한 단계로 개발한다.
- 각 단계가 끝날 때마다 문법 검사 또는 실행 확인을 수행한다.
- 한 커밋에는 하나의 논리적인 변경만 포함한다.
- 좌표를 수정할 때는 실제 스프라이트 이미지와 화면 출력 결과를 함께 확인한다.
- 반복 횟수, 정지 시간, 출력 배율, 캔버스 크기는 코드 상수로 관리한다.
- 모든 커밋 메시지와 커밋 본문은 한글로 작성한다.

## 8. 검증 기준

### 자동 검증

- Python 문법 검사를 통과한다.
- 정적 진단 오류가 없다.
- `git diff --check`를 통과한다.
- 모든 프레임 좌표가 스프라이트 이미지의 유효 영역 안에 있다.
- 프레임 좌표 하나당 캐릭터 하나만 포함되는지 확인한다.

### 실행 검증

| 항목 | 합격 기준 |
| --- | --- |
| 캔버스 | 1200 x 600 창이 열린다. |
| 프레임 출력 | 스프라이트 캐릭터가 한 번에 하나만 표시된다. |
| 확대 | 모든 프레임이 원본 크기의 4배로 표시된다. |
| 반복 | 각 동작이 5회 재생된다. |
| 정지 | 각 동작 뒤 마지막 프레임이 1초 유지된다. |
| 순환 | 마지막 동작 뒤 첫 동작으로 돌아간다. |
| 종료 | 창 닫기와 `ESC`로 오류 없이 종료된다. |
